# Исходники диаграмм

Диаграммы написаны на Mermaid и редактируются как текст. Они дополняют исходное изображение `docs/figures/architecture_figure.png`, которое сохранено без изменений.

- [Компоненты](components.mmd): процессы, доверительные границы и NFS-доступ.
- [Выдача блока и подтверждение](lease.mmd): SQL, heartbeat, C6, публикация и повтор.
- [Состояния задания](job-state.mmd): управление и завершение.
- [Публикация](publication.mmd): проверяемые этапы и восстановление после сбоя.

Просмотр возможен в Mermaid-совместимом Markdown/IDE; для экспорта используйте закреплённый в своей среде Mermaid CLI. Сборка Go и интерфейс не загружают Mermaid либо другие ресурсы из CDN.
