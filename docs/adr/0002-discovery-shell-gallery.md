# ADR-0002. Два этапа обработки, интерактивный SSH и галерея

Дата: 6 ноября 2026 года. Статус: принят владельцем через утверждённый план реализации.

## Основание

По замечаниям преподавателя владелец запросил отдельные операции парсинга и скачивания, полноценный терминал и галерею. Уточнения владельца: каталог содержит только разрешённые к скачиванию материалы, общий список объединяет доступные парсинги; shell без sudo; новая версия устанавливается на чистый стенд.

## Решение

В SQL сохраняются тип задания `discovery/download`, неизменяемая выборка скачивания, доступность материала и очередь превью. `available` — финальный результат парсинга; `completed` — подтверждённое скачивание. Числовой перебор и C6 сохраняются, разреженные выборки не превращаются в полный числовой диапазон. Перед загрузкой заново проверяются разрешение и канонический ID. Источник сдачного стенда — настоящий Kinescope с исходным ограничением 1 RPS.

Взамен ограниченного терминала ADR-0001 браузер получает xterm.js, WSS и настоящий SSH PTY. Отдельный пользователь `begom-shell` и порт 2223 обеспечивают обычный shell без sudo. Ограниченный RPC управления агентом остаётся на 2222 с отдельным ключом. Аудит терминала фиксирует сессию, не пытаясь интерпретировать интерактивный ввод как надёжный список команд.

Галерея и просмотр используют общий ACL опубликованных файлов. Превью и длительность создаются FFmpeg/FFprobe после публикации; отказ декодера не отменяет скачивание. Изображения входят в согласованные резервные копии как sidecar-файлы.

## Совместимость и последствия

API v2 требует согласованных версий координатора, агентов, CLI и UI. Старые задания v1 не интерпретируются автоматически; новый профиль имеет отдельные имена проекта, сеть, порты, секреты и тома. Обратная миграция не предоставляется. Существующие профили автоматически не удаляются.

Новые зависимости: локальные assets xterm.js 6.0.0/addon-fit 0.11.0 с контрольными суммами и лицензиями; OpenSSH и bash/procps/nano на рабочих узлах; FFmpeg на координаторе. Отдельный frontend-фреймворк и Node.js в рабочем приложении не добавляются.
